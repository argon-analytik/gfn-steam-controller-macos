# Visual assets

The hero and social image present the compatibility path between Steam,
macOS, the Steam Controller, and NVIDIA GeForce NOW. The icon files are
normalized to a 1024 × 1024 transparent canvas; the controller cutout also
uses a transparent background. `linkedin-cover.png` is 1200 × 627 pixels.

The Steam, NVIDIA, Apple, and Steam Controller names, marks, icons, and product
imagery belong to their respective owners. They are included for identification
and editorial presentation of this independent compatibility project. They are
not covered by the repository's MIT software license and do not imply
affiliation, endorsement, or sponsorship.

Generated presentation assets:

- `hero.png`: wide README artwork;
- `linkedin-cover.png`: LinkedIn-ready crop;
- `steam-controller-cutout.png`: transparent controller image;
- `icons/`: equally sized transparent platform icons.
